# 2026-08-03 工作日志

## 项目分析：钱罐罐记账后端 (qianguanguan-java)
- 对项目做了全面分析，产出架构图（分层：Controller → Service → MySQL/Redis/微信API）。
- 技术栈：Spring Boot 3.5.6 / Java 17 / MyBatis-Plus 3.5.7 / MySQL 8.4 / Redis / Spring Security + JWT(jjwt 0.11.5) / springdoc-openapi 2.7.0 / QQ SMTP 邮件。
- 业务：个人记账（账单/分类/统计）、邮箱+验证码登录/注册、微信小程序一键登录、Web 扫码登录、微信绑定、用户管理（SUPER_ADMIN）、文件上传。统一前缀 /api/business，端口 8888。
- 认证：JWT + Redis 签发时间戳双重校验；白名单路径放行；改密/改角色/禁用用户时删 Redis key 强制下线。
- 安全风险（重要，后续可优先修复）：
  1. application.yaml 明文硬编码微信 app-secret、QQ SMTP 授权码、数据库密码、JWT 密钥（弱密钥 1234567890abcdef...），docker-compose 中 MySQL root 密码明文 → 应改为环境变量/密钥管理。
  2. /upload 上传接口在白名单内无需认证，且未做文件类型白名单校验。
  3. 全局异常直接返回 e.getMessage()，可能泄露内部细节。
- 改进点：权限校验为 service 内手动判断而非 @PreAuthorize；无单元测试；统计用 likeRight 前缀匹配；GlobalResponseHandler 每次 new ObjectMapper。
