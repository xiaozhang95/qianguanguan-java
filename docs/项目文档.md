## 六、认证机制

### JWT + Redis 双重验证

1. **登录** → 签发含 `id`、`role`、`Date` 声明的 JWT（HMAC-SHA256）
2. **Redis** → 存储 `user_{userId}` 对应签发时间戳
3. **请求拦截** → `JwtAuthenticationFilter` 校验签名 + 比对 Redis 时间戳
4. **Token 失效** → 密码/角色变更时删除 Redis Key，使旧 Token 全部失效
5. **Token 过期** → 1 小时，支持刷新

### 角色权限
- **SUPER_ADMIN**：可管理用户状态和角色
- **USER**：只能操作自己的账单、分类和个人信息

### 安全白名单
登录、注册、验证码、扫码登录、微信绑定、Token 刷新、文件上传、Swagger 页面均无需 JWT 认证

## 七、业务逻辑要点

### 账单模块
- 用户只能查看/编辑/删除自己的账单
- 列表支持按类型、分类、日期范围筛选
- 统计按月份/日期聚合收入与支出

### 分类模块
- 系统默认分类（user_id 为 NULL）不可删除
- 编辑系统分类时自动创建用户专属副本
- 用户可增删改自己的分类

### 扫码登录
- 生成16位场景ID → 调用微信生成小程序码 → Web 端轮询状态 → 小程序扫码确认 → 签发JWT

### 微信绑定
- 已登录用户生成绑定二维码 → 小程序扫码确认 → 更新 t_user.wid

## 十、代码规范

- **Lombok**：`@Data`、`@Builder`、`@RequiredArgsConstructor`、`@Slf4j` 广泛应用于实体和 Service
- **依赖注入**：构造器注入，`final` 字段 + `@RequiredArgsConstructor`
- **ORM 查询**：MyBatis-Plus `LambdaQueryWrapper` 类型安全查询
- **统一响应**：`Response<T>` 全局封装 `{code, msg, data}`
- **异常处理**：集中化 `GlobalResponseHandler` + `@ExceptionHandler`
- **Long 序列化**：ID 字段序列化为 String，避免 JavaScript 精度丢失
- **数据隔离**：从 JWT 中提取 userId，确保用户只能访问自身数据
- **中文注释**：所有 Java 文件包含详细中文 Javadoc
