## 登录方式

| 方式 | 适用端 | 说明 |
|------|--------|------|
| 账号密码登录 | Web | 用户名 + 密码 + 图形验证码 |
| 一键登录 | 小程序 | `wx.login()` → code 换 openId |
| **微信扫码登录** | Web ← 小程序 | Web 展示小程序码 → 扫码确认 → 跨端登录 |

### 关键 Redis 设计

```
二维码生成时:
  HSET qr_login:{sceneId} status "pending"
  HSET qr_login:{sceneId} token ""
  EXPIRE qr_login:{sceneId} 300    # 5 分钟过期

确认登录时:
  HSET qr_login:{sceneId} status "confirmed"
  HSET qr_login:{sceneId} token "Bearer xxx..."

轮询获取后:
  DEL qr_login:{sceneId}           # 一次性使用，立即删除
```

## 后端 API

### 扫码登录接口

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| GET | `/api/business/qr-login/scene` | 生成小程序码 + 场景ID | 否（白名单） |
| GET | `/api/business/qr-login/status?sceneId=xxx` | 轮询场景码状态 | 否（白名单） |
| POST | `/api/business/qr-login/confirm` | 小程序确认登录 | 否（白名单） |

### 其他登录接口

| 方法 | 路径 | 说明 | 鉴权 |
|------|------|------|------|
| POST | `/api/business/login` | 账号密码登录 | 否 |
| POST | `/api/business/register` | 注册 | 否 |
| GET | `/api/business/user/LoginByWid?code=xxx` | 小程序一键登录 | 否 |

### 响应格式

所有接口统一返回：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { ... }
}
```

## JWT 认证机制

```
签发流程:
  userId + role + 时间戳 → HS256 签名 → "Bearer " + token

校验流程:
  每个请求 → JwtAuthenticationFilter
    → 校验 HMAC 签名
    → 从 Redis 读取 "user_{userId}" 时间戳
    → 比较 token 中的 Date 与 Redis 中的时间戳是否一致
    → 不一致 → 返回 401 (token 已被新登录/强制下线失效)
```

**强制下线**：修改密码、角色变更、状态切换时删除 Redis 中的 `user_{userId}` 键，使得所有现有 token 立即失效。

## 用户表 (t_user)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 雪花主键 |
| username | VARCHAR(50) | 用户名，唯一 |
| password | VARCHAR(255) | BCrypt 加密 |
| name | VARCHAR(50) | 昵称 |
| role | VARCHAR(50) | SUPER_ADMIN / ADMIN / USER |
| wid | VARCHAR(100) | 微信 OpenID，唯一，**扫码登录绑定字段** |
| avatar | LONGTEXT | 头像路径 |
| status | TINYINT | 1-启用 0-禁用 |

## 微信小程序码生成

调用微信 `getwxacodeunlimit` API：
```
POST https://api.weixin.qq.com/wxa/getwxacodeunlimit?access_token=TOKEN

{
  "scene": "aB3xK9mP2qW7yR",    // 16 位随机场景码
  "page": "pages/qr-login/index", // 扫码后打开的页面
  "check_path": false,
  "width": 280
}
```

- `access_token` 从 `https://api.weixin.qq.com/cgi-bin/token` 获取，缓存到 Redis 7000 秒
- **要求小程序已发布上线**，否则返回 412
- `scene` 最长 32 字符，传入小程序 `onLoad(options.scene)`
